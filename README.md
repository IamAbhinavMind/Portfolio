# Signal — Abhinav's Personal Portfolio (MVP)

> **Codename:** Signal  
> **Aesthetic:** Deep Focus (Calm, Uncluttered, High-Contrast, Honest)  
> **Tech Stack:** Vanilla HTML5, CSS3, ES6 JavaScript (Zero dependencies, <50ms load time)

---

## 🚀 Quick Start & Local Preview

### Option 1: Open Directly in Browser
Double-click `index.html` or drag it into any web browser (Chrome, Edge, Brave, Safari).

### Option 2: Run Local Development Server
From this project directory, run:
```powershell
python -m http.server 8000
```
Then visit: [http://localhost:8000](http://localhost:8000)

## 🚢 Deployment

This site has zero build steps and is 100% static:

- **GitHub Pages:** Push this repository to GitHub and enable GitHub Pages in Settings → Pages (Branch: `main`, Folder: `/root`).
- **Vercel / Netlify:** Drag-and-drop this folder or connect the GitHub repo — it will deploy instantly with zero configuration.
